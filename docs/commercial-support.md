# Commercial support

PermitDiff is Apache-2.0 open source. Commercial work is intentionally focused on adoption, not feature lock-in.

## Engagements

- **Permission architecture review** — map tools, principals, trust boundaries, approvals, and failure modes.
- **Regression corpus design** — convert workflows, incidents, and abuse cases into a reviewable test corpus.
- **CI rollout** — integrate PermitDiff with GitHub Actions, SARIF, branch protection, and release evidence.
- **Policy migration** — translate existing YAML/JSON rules into deterministic, testable semantics.
- **Private adapters** — connect internal policy formats and approval systems without exposing proprietary data.

## Product path

The open-source core remains local and deterministic. Potential paid layers are team workflow, private adapters, managed evidence retention, and enterprise support—not a weaker community edition.

For an assessment, open a private contact channel from the maintainer profile rather than sharing sensitive policies in a public issue.
