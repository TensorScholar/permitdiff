# Exploratory corpus

This directory is intentionally mutable.

Use it for schema/harness development, synthetic coverage cases, and public historical cases that have not yet passed the confirmatory freeze process. Results from this directory must be labeled exploratory and must not be used to upgrade PermitDiff's evidence maturity.

`manifest.example.json` is a structurally representative example only. Replace placeholder digests and reviewer metadata before running any real exploratory case.
