# Code of conduct

We are committed to a professional, technically rigorous, harassment-free project environment.

Contributors must communicate respectfully, critique ideas rather than people, disclose relevant conflicts, avoid publishing private or sensitive data, and accept maintainer decisions made to preserve project security and scope.

Unacceptable behavior includes harassment, discriminatory conduct, threats, doxxing, sexualized attention, deliberate disruption, or knowingly misleading security claims.

Report conduct concerns privately through the maintainer contact methods on the GitHub profile. Maintainers may edit, reject, or remove contributions and may temporarily or permanently restrict participation when necessary.
