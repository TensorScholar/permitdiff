# Governance

PermitDiff uses a maintainer-led governance model during the alpha phase.

The lead maintainer owns release decisions, security response, scope, and schema compatibility. Significant semantic changes require a public issue, an ADR, reviewable tests, and a documented migration path.

The project will add maintainers based on sustained, high-quality contribution and demonstrated judgment around security boundaries. Commit access does not imply unilateral release authority.

Decisions optimize for user safety, deterministic behavior, small operational surface, and evidence over feature count.
